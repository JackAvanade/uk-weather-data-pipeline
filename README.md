# UK Weather Data Pipeline

## Overview

This project extracts forecast weather data from the Open-Meteo API using Python.

The raw API response is transformed using Pandas and visualised in Power BI.

## Technologies

- Python
- Pandas
- REST APIs
- Power BI
- GitHub

## Data Pipeline

Open-Meteo API
↓
Python
↓
JSON
↓
CSV
↓
Power BI

## Features

- Multi-city weather forecasts
- Newcastle
- London
- Manchester
- Edinburgh
- Interactive Power BI dashboard
- City slicer
- Temperature comparison charts
- Forecast matrix
